How it works

Five steps to a clean slate

  1. 1Open claude.ai in Chrome
  2. 2Click "Select chats" or press Ctrl+Shift+X
  3. 3Click conversations to toggle, or press Ctrl+A to select all
  4. 4Press Enter — then press again within 2 s to confirm
  5. 5Done — selected chats are deleted instantly

FAQ

Frequently asked questions

Can you delete multiple Claude conversations at once?

Claude has no built-in bulk delete — you can only remove one conversation at a time from the sidebar. Claude Chat Cleaner adds that missing feature: select any number of conversations and delete them all in a single action.

How do I bulk delete Claude history?

Install Claude Chat Cleaner from the Chrome Web Store. On claude.ai, press Ctrl+Shift+X (or ⌘⇧X on Mac) to enter selection mode, click conversations or press Ctrl+A to select all, then press Enter twice to confirm. The extension processes all deletions automatically.

Is Claude Chat Cleaner safe to use?

Yes. The extension uses your existing Claude login session and Claude's own API — no data is ever sent to a third-party server. It requires only one browser permission: access to claude.ai. The source code is open on GitHub.

Does it work on Mac?

Yes. Use ⌘⇧X to toggle selection mode and ⌘A to select all conversations. The extension works in Chrome on both macOS and Windows.

Does it work with Claude Pro, Team, or Enterprise?

Yes. Claude Chat Cleaner works with all Claude plans — Free, Pro, Team, and Enterprise — as long as you're using Google Chrome.

Will deleting conversations affect my Claude account?

No. Deleting conversations only removes them from your chat history. Your Claude subscription, Projects, and account settings are completely unaffected. A double-confirm step (press Enter twice) prevents accidental deletions.

What happens if a deletion fails?

Claude Chat Cleaner uses an optimistic UI — selected chats disappear from the sidebar immediately for a snappy feel, but are automatically restored if the API call fails. No conversations are silently lost.

Is Claude Chat Cleaner really free?

Yes — completely free with no usage limits, no sign-up required, and no paid tier. The extension is open source and always will be.
